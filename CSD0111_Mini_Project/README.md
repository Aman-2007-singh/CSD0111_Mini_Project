# Daily Task Management System
**Course:** CSD0111 – Project Studio-I

## Overview
Users can add tasks, select priority, mark tasks completed or undo completion, delete tasks and view task counts.

## Project Contents
- 01_Word_Documentation – report in DOCX and PDF
- 02_Excel_Workbook – 25 sample task records, formulas and two charts
- 03_PowerPoint – 9-slide presentation
- 04_Website – HTML, CSS and JavaScript
- 05_Screenshots – five sample interface preview images

## Technologies Used
- HTML
- CSS
- JavaScript
- Microsoft Word
- Microsoft Excel
- Microsoft PowerPoint

## Run the website
Open 04_Website and double-click index.html.

## Four JavaScript functions
1. Add Task
2. Delete Task
3. Mark Completed / Undo
4. Update total, completed and pending task counts
